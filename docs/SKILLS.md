# Навыки разработки TMGF

Отобраны по задаче, без установки всех доступных навыков.

| Навык | Название для проекта | Назначение |
|---|---|---|
| brainstorming | Проектирование игры | Правила, границы MVP, пользовательский опыт |
| writing-plans | План разработки | Ясные интерфейсы модулей и проверки |
| test-driven-development | Разработка через тесты | Детерминизм матчей, прогресс, сохранения |
| systematic-debugging | Диагностика ошибок | Исправление причины сбоя |
| verification-before-completion | Проверка результата | Только подтверждённые заявления о готовности |
| requesting-code-review | Независимая проверка кода | Проверка целостности готовой игры |
| playwright | Проверка браузерной игры | Установлен из openai/skills; браузер в этом сеансе проверяется встроенными инструментами |
| gh-fix-ci | Диагностика проверок GitHub | Установлен из openai/skills; применять при сбоях CI |

Браузерные проверки текущего сеанса проводятся доступным встроенным управлением браузером. Публикация — GitHub и GitHub Pages, как запросил пользователь. Sites, Figma, платные API и генерация растровых ассетов не требуются: графика собственная пиксельная, рисуется в буфере 320×180 с ограниченной палитрой.

Русификация игровых приёмов находится в data.js. Системные идентификаторы установленных навыков не переименовываются: таблица даёт им русские описательные названия без нарушения подключения.
