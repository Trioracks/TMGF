# TMGF 0.0.0.1 — восстановление игрового цикла

Коррекция пользователя: предыдущая версия реализовала другую игру. Цель — перенести взаимодействие Tecmo Cup: свободное продвижение с мячом, добровольное меню, выбор области паса, автоматические встречи и заранее назначенные индивидуальные действия нескольких игроков. Визуал целиком 16-битный, в духе Mega Drive, с собственными узнаваемыми спрайтами.

## Что подтверждено

Локальная ROM: стрелки управляют бегом, C открывает меню добровольно; при сближении соперников начинается встреча и останавливается время. При нескольких соперниках действия назначаются заранее: дриблинг первому, пас второму → выбор точки → сначала анимация дриблинга, затем паса. После разрешения игра возвращается к бегу автоматически. Подробности: ORIGINAL-FLOW.md. Оригинал работает непрерывно; один шаг на нажатие — явно запрошенная пользователем адаптация.

## Правила и состояния

- `field`: стрелки/WASD = один ортогональный шаг. Свободное движение не бросает кубик на дриблинг. Пробел = меню без расхода времени.
- `command`: добровольный выбор паса/навеса/удара/комбинации; отмена возвращает к бегу.
- `target`: отдельное поле, свободный курсор мышью или стрелками, Enter подтверждает направление передачи. Игроки и время стоят. Отмена возвращает в исходное меню.
- `encounter`: от одного до трёх близких защитников видны в сцене; каждый сохраняет лицо, причёску, форму и номер. Нападающий планирует дриблинг для очередного защитника или завершает очередь пасом/ударом. В защите пользователь назначает каждому отбор/перехват/блок/ожидание до раскрытия плана бота. После последнего назначения проверки выполняются по очереди; потеря прерывает очередь.
- `air`: прибытие к области → борьба за верх → приём/пропуск/удар, с сохранением отдельных характеристик и встречных намерений.
- `keeper`: при ударе бота пользователь выбирает поймать или отбить. Удары с нашей стороны встречает бот-вратарь.
- Короткая постановка показывает порядок событий и автоматически возвращает к следующему состоянию. Она блокирует повторный ввод. Перезагрузка восстанавливает уже рассчитанный исход, не бросает кубики заново.

Поле 25×15, один игровой шаг или завершённый эпизод = одна минута, два тайма по45. Назначение планов/курсор/отмена ничего не расходуют. При владении бота свободное движение идёт автоматически; на встрече/верховом мяче/действии вратаря бот ждёт человека. При скрытой вкладке и уходе в клуб таймер бота останавливается.

## Границы достоверности

Радиус, конкретные веса вероятностей и длительность хода — явно заданные правила реконструкции. Они не объявляются декомпилированными формулами ROM. Сохраняются все13 характеристик, рост, усталость и зависимость от расстояния. Неподходящее намерение уменьшает шанс отбора, но не делает ни один исход гарантированным.

## Проверки до выпуска

1. Движение во все четыре стороны, границы; меню/курсор не тратят ходы и не двигают ботов.
2. Один/два/три близких соперника, индивидуальное планирование, прерывание после потери; ошибочный подкат при пасе и успешный перехват следующим защитником.
3. Передача в точку и партнёру, верховая борьба, выбор вратаря, дальность и энергия.
4. Несколько сотен полных матчей, перерыв/финал, сохранение каждой фазы и перенос карьеры0.0.0.0.
5. Браузером: стрелки → пробел → пас → курсор → передача; столкновение → планы → правильная последовательность сцен; весь матч и мобильный экран.
6. Независимое ревью, версия0.0.0.1, GitHub Actions и проверка опубликованного сайта.
