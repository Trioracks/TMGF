# План реализации TMGF

> Исполнение: разработка в текущем чате, тесты сначала; независимая проверка итогового кода.

**Цель:** играемый публичный MVP 0.0.0.0.
**Архитектура:** независимые data, engine, career, storage; browser app, pitch и audio используют их интерфейсы.
**Стек:** HTML/CSS/JavaScript, Node test runner, GitHub Pages.
**Спецификация:** DESIGN.md.

## Ограничения

Все названия на русском. Версия 0.0.0.0, затем 0.0.0.1. Чистый статический сайт, относительные пути. Исследовательские данные и ROM не публикуются.

## Риски для проверки

- Повторное нажатие на завершение матча не должно начислять очки дважды.
- Исчерпанная энергия не блокирует весь матч: доступно безопасное действие.
- Повреждённое сохранение и имя с HTML не выполняют код и не ломают интерфейс.
- Перерыв при переходе через 45 минут срабатывает ровно один раз.
- После сезона и кубка всегда есть следующий матч или явное действие перехода.

## Журнал решений

- Пользователь явно поручил реализацию и публикацию; работа продолжается без повторных разрешений на уже заказанные действия.
